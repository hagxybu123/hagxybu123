### 👩‍💻 关于我

我是**天逸**，一名在学编程的学生。名字里的"逸"取"逃逸"之意——逃出按部就班的剧本，
去做那些没人替我决定的事。编程对我来说就是这样的出口：**它不看你出身，只看你想清楚没有。**

课堂之外我是个二次元，如果只能选一个最爱的名字，那一定是**洛天依**。
我反复写过她的设定，也把那份审美搬进了自己的主页：宝蓝、冰蓝、白蕾丝，还有一整片星空。
